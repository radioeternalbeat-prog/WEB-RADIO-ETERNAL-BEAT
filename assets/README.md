# Carpeta `assets/`

Coloca aquí los siguientes archivos (mismo nombre exacto):

- `logo.png` — tu logo (recomendado: fondo transparente, cuadrado, mínimo 512x512px).
- `favicon.png` — ícono pequeño para la pestaña del navegador (32x32 o 64x64px). Si no tienes uno, puedes usar una versión reducida del logo.

Mientras no subas `logo.png`, el sitio simplemente no mostrará el logo (no se rompe nada).
