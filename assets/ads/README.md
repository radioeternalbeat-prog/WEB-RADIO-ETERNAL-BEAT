# Espacios publicitarios (`assets/ads/`)

Sube tus banners publicitarios con estos nombres exactos para que aparezcan automáticamente en el sitio:

| Archivo | Ubicación en la web | Tamaño recomendado |
|---|---|---|
| `banner-top.jpg` | Debajo del menú principal | 1200x150 px |
| `banner-strip.jpg` | Entre el reproductor y la sección de video/chat | 1200x200 px |
| `banner-strip-2.jpg` | Entre chat y el historial de canciones | 1200x200 px |
| `banner-bottom.jpg` | Antes del pie de página | 1200x200 px |

Si no subes una imagen, ese espacio se muestra marcado como "Espacio disponible para publicidad" (no rompe el diseño).

Puedes agregar más espacios copiando un bloque `<div class="ad-slot ...">` en `index.html` y una imagen nueva aquí.
