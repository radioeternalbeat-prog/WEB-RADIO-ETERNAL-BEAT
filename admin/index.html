¿Cómo obtengo mi token?
  1. Entra a github.com/settings/personal-access-tokens/new
  2. En Token name escribe: Panel Radio
  3. En Expiration elige 90 días (o lo que prefieras)
  4. En Repository access elige Only select repositories y selecciona WEB-RADIO-ETERNAL-BEAT
  5. En Permissions → Repository permissions → Contents, elige Read and write
  6. Click en Generate token y copia el código que aparece
  7. Pégalo aquí arriba

Guarda tu token en un lugar seguro y no lo compartas. Solo se guarda en este navegador, nunca se sube al sitio.
